ДИВОПИС

Конвертер Unicode-тексту: діакритика, старокириличні двійники, фонетичні/модифікаторні знаки, псевдоперевернення та інші контрольовані дивності. Усе копіюється як звичайний текст, а не як картинка.

Важливо: Unicode-код може бути цілком валідним, але вигляд залежить від шрифту та програми. Тому «100% однаково виглядатиме всюди» для екзотичних символів не існує. Ця сторінка не підміняє літери невидимими символами і не використовує приватні кодові точки.

Діакритики U+0300–U+036F стандартно можуть комбінуватися з кирилицею. Саме це дає найбільш повне покриття всіх 33 українських літер, хоча конкретне позиціонування - визначає шрифт.

✓ = перетворення визначене для кожної літери; ◐ = художня підміна існує лише для частини абетки або є наближеною; × = окремого Unicode-алфавіту для української кирилиці немає.

Клацніть стиль вище, щоб побачити всю абетку. Це корисно для перевірки Ґ/Є/І/Ї, на яких більшість «fancy text» генераторів раптом згадують, що вони насправді зроблені тільки для латиниці.

Може повністю локально працювати у браузері.
