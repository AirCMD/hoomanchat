Службова сторінка. Тут зібрані інструменти для наповнення Гуменчату. Звичайним відвідувачам тут робити просто нічого.
Генератори
  • Генератор гумгайлів
    Створення HTML-сторінки профіля персонажа та запису для списку гуменів.
    profile-generator.html
  • Генератор дописів (гумгайли)
    Статичний HTML блоків profile-post з коментарями для сторінок гумгайлів або ж профілів.
    profpost-generator.html
  • Генератор островів
    Створення HTML-сторінки для острова.
    island-generator.html
  • Генератор дописів острова
    Масив initialPostsData (title, body, likes, date, comments) для скрипта острова.
    island-post-generator.html
  • Генератор дописів острова з картинками
    Масив initialPostsData (title, body, likes, date, comments) для скрипта острова.
    island-postimg-generator.html
  • Генератор коментарів
    Коментарі з ніками та посиланнями на гумгайли, профілі.
    comment-generator.html
Швидкі посилання
  • Список гуменів (JSON)
    profiles/hoomen-list.json — джерело для сторінки «Гумени».
  • Сторінка «Гумени»
    Перевірка пагінації та карток після змін у JSON.
  • Острови
    Список спільнот.
  • Арчат
    Приватні переписки.
Як додати свій генератор
Поклади .html у корінь сайту (або в папку generators/) і додай ще один dev-item у цей список із потрібним href.
Пам'ятай та дотримуйся ПРАВИЛ нашого ресурсу.
